# App Store 图标

[English](README.md) | **中文**

在思源笔记里搜索 App Store 应用图标，一键插入正文或设为文档图标。

## 功能

- 顶栏图标，或快捷键 `Alt + Shift + A` 打开搜索面板
- 调用 Apple iTunes Search API，支持中国大陆、中国香港、中国台湾、美国、日本、英国六个区域
- 中文、英文关键词都能搜
- **左键点击**：插入到当前文档的光标位置
- **右键点击**：弹出菜单，可选「设为文档图标」或「仅下载图标」
- **最近使用**：面板顶部记住最近用过的图标，一次点击直接用
- **已下载标记**：已存在同名图标的搜索结果右上角会有蓝点
- 图标保存到 `data/emojis/appstore/`，图标值形如 `appstore/微信.png`

## 设置

插件设置里可以调整：

- **默认商店区域**：打开面板时默认选中哪个 App Store 区域
- **图标圆角**：保存时把方形原图裁成 22% 圆角，与思源其他图标风格统一；关闭则保留 App Store 原始方角
- **最近使用数量**：0 到 20，0 表示关闭该功能

设置通过思源的插件数据接口保存，会随 `data/` 目录一起同步。

默认快捷键固定为 `Alt + Shift + A`。如需修改，请到 **设置 → 键绑定** 搜索「App Store 图标」，在那里改能立即生效、也能看到冲突提示。

## 使用

1. 点击顶栏右侧的放大镜图标，或按 `Alt + Shift + A`
2. 输入应用名（如 `微信`、`Spotify`），回车
3. 左键插入，右键更多操作

图标会插入到**光标所在块的后面**，单独占一段。这是思源内核 API 的结构限制：`protyle.insert` 传入裸 `<img>` 会被 Lute 判定为 `NodeInlineHTML` 而丢弃，所以走的是 `/api/block/insertBlock` 的 markdown 通道。

图标会立刻出现在思源的图标面板里（`appstore` 分组），也可以当作表情插入正文。

## 常见问题

**为什么搜不到某个 App？**

切换右上角的区域。部分应用只在特定区域商店上架。

**图标存在哪？**

`工作空间/data/emojis/appstore/`。这个目录在同步范围内，会跟随 `data/` 一起同步到其他设备。

**卸载插件会删除图标吗？**

不会。已下载的图标文件保留，只是不能再通过面板搜新的。
